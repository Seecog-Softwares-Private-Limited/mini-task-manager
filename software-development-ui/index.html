OpsPick Platform · Vertical Concept

Software Development UI

A Jira‑style task & issue tracking skin for the existing OpsPick codebase — same shell, sidebar, color system, and components as the current product, retargeted with sprint/epic/issue concepts for software teams instead of generic ops tasks.

Project→ stays Project
Task→ becomes Issue (Bug / Story / Task)
Recurring Tasks→ becomes Backlog + Sprints
Analytics→ becomes Sprint Reports
01 · Board

Sprint board

Active-sprint Kanban with issue types, story points, priority and epic tags.
02 · Backlog

Backlog & sprint planning

Grouped by active / planned sprint and unscheduled backlog, ready to drag into sprints.
03 · Issue detail

Issue detail

Subtasks, linked issues, comments, and a field sidebar (status, sprint, epic, points).
04 · Roadmap

Epics roadmap

Quarterly timeline of epics with progress and status against the plan.
05 · Reports

Sprint reports

Burndown, velocity, and scope-change KPIs per sprint.
06 · Projects

Projects overview

Workspace-level grid of Scrum/Kanban projects with lead and progress.
Self-contained HTML mockups — open any file directly in a browser. Colors and spacing are pulled from the live app's design tokens (frontend/tailwind.config.ts, globals.css) and the existing marketing/mockups/*.html reference set.
